# 日本株 需給診断(日本株 需給・理論値ベース相場診断)

呼び出し名: 「日本株 需給診断」。ユーザーが「需給診断して」「日本株の需給診断」と言ったら、このスキルを使う。

「今の日経平均はどういう状況か」「暴落/反発の条件は揃っているか」を、下記の手法で診断する。
手法は特定の投資系YouTuberの仮説を整理したもの。**閾値は経験則であり、統計的に検証されたものではない**。出力では必ずその前提を明記し、投資助言にならないようにする。

## 実行手順

1. データ収集(下表)。まず `pip install -q yfinance pandas` のあと `python get_market_info/yf_prices.py diag --md <スクラッチパッド>/diag.md` を実行して価格・テクニカル・クロスマーケットを取る。残りは WebSearch で集め、日経平均のPER・BPSが分かったら `--per-w/--per-i/--bps-w/--bps-i` を付けて再実行し、理論値ラインを出す。取れなかった項目は推測せず「未取得」と書く。
2. 各セクションの判定を計算する。数値は必ず実際に計算し、頭の中で概算しない。
3. 8条件チェックリストで点灯数を数える。
4. 出力テンプレートに沿ってレポートを作り、`reports/YYYY-MM-DD_jp-supply-demand.md` に保存する。TOPIXは `^TOPX` が取れないため 1306.T で代替し、その旨をレポートに書く。

## データ収集

| 項目 | 入手先の目安 |
|---|---|
| 日経平均・TOPIX・S&P500・ドル円・VIX・SOX の日足とテクニカル | `python get_market_info/yf_prices.py diag` で価格とテクニカルを取得する(PER・BPSが分かれば `--per-w/--per-i/--bps-w/--bps-i` を渡す)。スクリプトがない環境では yfinance(^N225, 1306.T, ^GSPC, JPY=X, ^VIX, ^SOX) |
| 信用取引残高(売残・買残、金額ベース、週次) | JPX「信用取引残高」二市場合計(東証・名証)。WebSearch/WebFetchで最新週を取得 |
| 日経レバETF(1570)の信用倍率 | 日本証券金融または証券各社の信用残ページ |
| 日経平均EPS・PER・PBR | 日本経済新聞社「日経平均プロフィル」 |
| 投資主体別売買動向(海外投資家) | JPX 投資主体別売買動向(週次) |
| 空売り比率 | JPX 空売り集計(日次) |
| 騰落レシオ | 東証プライム騰落レシオ(6日・25日) |
| 米国セクター・金利・金・BTC等 | WebSearchまたはyfinance |

注意: 元動画の「日合計/石合計」は音声認識の誤りで、実際は**二市場合計**(東証・名証の信用取引残高)を指すと思われる。定義が不確かな場合は、使った指標をレポートに明記する。

## 分析A: 需給(最重要)

- **信用売り残(金額)**: 8,000億円を多い/少ないの転換点とみなす(仮説・固定値扱い)。
  - 以上: ショートカバーの燃料あり。踏み上げが持続しやすい。
  - 未満: 燃料枯渇。ショートカバーは短命(騙し上げ)になりやすい。
- **信用倍率** = 買い残÷売り残(金額ベース)。評価損益率がマイナス2桁%なら含み損の投げ売りリスクが高い。
- **日経レバ信用倍率**: 1倍未満は買い圧力の補強。1倍超は燃料枯渇。10倍超は特に脆弱。
- **NS倍率** = 日経平均÷S&P500。上昇=ショートカバー起動スイッチON、低下=OFF。直近20日程度の方向で判定する。
- **空売り比率**: 40%超が続けばショートが溜まっていた可能性。
- **カレンダー要因**: 6月高値で信用買いした玉の半年期日(12月)、年末の損益通算売り。11〜12月に需給悪化要因として加点して考える。

## 分析B: テクニカル(日経平均・TOPIX)

- **バンドウォーク**: 日足が-2σに沿って推移しているか。終了サインは、(1)-2σから剥がれる、(2)パラボリックとMACDが上昇転換、(3)25日線(ボリンジャー中央線)まで戻す。
- **戻り波形**: 中央線で頭打ちを繰り返すなら下落トレンド継続。中央線まで押して反発するなら上昇トレンド。
- **騙しGCの判定**: MACDのGCが、シグナル線とMACD線がともに切り下がった状態で出ていれば騙しの可能性が高い。
- **移動平均線**: 25日と200日のクロス、50/75/100日が200日をGC/DCする状況を確認。
- **騰落レシオ(6日)**: 50前後以下なら売られすぎ。短期反発の余地として別枠で記述する。
- **過去局面との類似**: 直近の値動きを過去の暴落局面(例: 2018年)と重ねて比較してよいが、ズレた点を必ず記述する。

## 分析C: 理論値(EPS × PER、PBR)

- 日経平均の理論値 = EPS × PER。PER 14/15/16/21倍のラインを計算する。
- **EPSの前日比(下方修正)**を確認。下方修正で理論値が下がると日経平均も下がりやすい、という見立て。
- **PER16倍**: 平常時の上値目安。売り残が8,000億円以上のときだけ16倍超が許容されたという仮説。燃料が尽きている局面では16倍を強い上値抵抗として扱う。
- **PBR2倍**: 直近高値の天井ライン。PERより重要度が高いという見方。
- 現在値が各ラインのどの位置にあるか、上値余地と下値余地を円とパーセントで出す。

## 分析D: 資金フロー・センチメント

- **海外投資家**: 投資主体別売買が直近3週以上売り越しか。ドル建て日経平均(日経平均÷ドル円)のRSIが下値抵抗ラインを割ったか。
- **VIX × MACD**: VIXのMACDがGC=株安サイン、DC=株高サイン(期待値8割という主張だが、サンプルが少ない旨を併記)。
- **NT倍率**: 低下ならTOPIX優位。バリュー・高配当・ディフェンシブへのローテーション。

## 分析E: クロスマーケット

米国主要指数とセクター、米金利、SOX、中国・韓国・欧州・インド、金・銀・銅、ビットコイン、REITを確認し、「全面安(リスクオフ)」か「半導体だけ」かを切り分ける。株・債券・金が同時に売られていればドル高・流動性要因を疑う。

## 暴落8条件チェックリスト

点灯/非点灯/未取得で判定し、点灯数を出す。

1. バンドウォーク終了サインが出た
2. 信用売り残が8,000億円未満
3. 日経レバ信用倍率が1倍以上
4. 日本株優位性の低下(NS倍率の低下)
5. 日経平均理論値の下方修正
6. 海外投資家の売り越し
7. VIXとMACDのゴールデンクロス
8. PBR2倍が天井として意識され、好決算銘柄が決算後に下落

点灯数が多いほど下落リスクが高い、という目安で扱う。点灯数と実際の下落幅の関係は検証されていないため、確率として断定しない。

## 銘柄・テーマの選別視点

- 売られやすい: 高値圏で信用買いが多く含み損、200日線と中期線が断続的にデッドクロス。
- 底堅い: 長期線が断続的にゴールデンクロス、出遅れバリュー、需給が軽い。
- 年末は二極化相場になりやすいという経験則を、信用倍率が高止まりしているかで確認する。

## 出力テンプレート

1. **結論(3行以内)**: 現在の局面、8条件の点灯数、最も重要な要因
2. **需給 / テクニカル / 理論値 / 資金フロー / クロスマーケット**: 各セクションで、数値と判定を表で示す
3. **チェックリスト表**: 8条件の判定
4. **シナリオ**: 反発シナリオと続落シナリオ。それぞれ、確認すべき水準(PERライン、25日線、200日線など)と、変化のサイン
5. **データの鮮度と限界**: 各データの基準日、未取得項目、使った代替指標
6. **免責**: 投資助言ではなく、仮説ベースの診断である旨

## 守ること

- 数値の出典と基準日を必ず併記する。
- 8,000億円、PER16倍の条件、スイッチ理論は仮説であると明記し、断定的な売買推奨をしない。
- 売買の指示ではなく、判断材料と確認すべき条件を示す。
- 音声や外部記事に由来する数値は、一次データで再計算して確かめる。
